# Demo Video skill

A skill for AI coding agents (Claude Code): make a narrated demo or promo video of a project's live site or app — scripted browser takes with agent-browser, voice-over with Gemini, burned-in captions, a synthesized music bed, ffmpeg edit and a shareable link.

```bash
npx skills add open-kbs/skills-demo-video
```

See [`skills/demo-video/SKILL.md`](skills/demo-video/SKILL.md) for the pipeline and `skills/demo-video/examples/` for a complete edit plan, narrator script and animated cards.
